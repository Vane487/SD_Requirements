# Архітектура програмного забезпечення — лабораторні №3–13

Навчальний Java-проєкт інтернет-магазину, який демонструє породжувальні, структурні та поведінкові шаблони проєктування.

## Лабораторні

| ЛР | Шаблони |
|---|---|
| 3–5 | Singleton, Prototype, Factory Method, Abstract Factory, Builder, Object Pool |
| 6 | Adapter, Bridge |
| 7 | Composite, Flyweight |
| 8 | Decorator, Proxy |
| 9 | Chain of Responsibility, Command |
| 10 | Iterator, Mediator |
| 11 | Memento, Observer |
| 12 | State, Strategy |
| 13 | Template Method, Visitor |

## Запуск

Потрібна Java 17 або новіша.

```bash
./run.sh demo
./run.sh test
./run.sh javadoc
```

Повний опис проєкту та відповідності вимогам міститься в `README.txt`. Детальне пояснення ЛР8–13 — `docs/Пояснення_ЛР8-13.md`. Зовнішні платіжні, складські та сповіщувальні системи в прикладах імітуються консольними заглушками.
